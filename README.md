# Electrosys Power Showcase

Build a modern, premium, fully responsive corporate business showcase website for a company called "Electrosys".

IMPORTANT:

This is a professional business showcase website, NOT an e-commerce website.

There will be:

- No login

- No admin dashboard

- No shopping cart

- No payment gateway

- No inventory system

- No customer account system

- No custom backend/database for the initial version

The website should focus on company presentation, products, brands, services and customer enquiries.

---

HOME PAGE INITIAL LOADING

---

Create a cinematic initial loading experience.

Sequence:

1. Website loads

2. Full-screen preloader appears

3. Electrosys logo appears in the center

4. Logo has a subtle elegant animation

5. Preloader disappears

6. A full-screen black/dark overlay appears

7. The black overlay smoothly moves upward from bottom to top / reveals the page

8. Home hero becomes visible

9. Hero content smoothly enters

This transition should feel premium and similar to the provided reference screenshots.

Do NOT make it overly long.
